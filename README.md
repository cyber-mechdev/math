# 高数雷霆助教｜机器人工程分章节考点版

浙江理工大学《高等数学 A1》期末复习单页应用。**整个网站只有一个 `index.html`**，KaTeX 与字体已全部内联，断网也能正常渲染公式。

## 功能

- **12 章固定导航**：函数极限与连续 → 无穷级数，按期末高频考点组织
- **每章四块**：考点卡片（适用条件 / 易错坑 / 机器人关联）→ 本校真题摘录 → 分层练习（基础 / 中档 / 拔高）→ 章节检测卷（100 分制，逐题批改、标注得分点与扣分原因）
- **本校历年真题**：浙江理工大学 2025—2026、2024—2025 两届高数 A 期末 A 卷，共 42 题，含官方答案与逐题解析，可按卷切换、单题看答案、一键记错题
- **严厉助教对话**：不写步骤不给答案；说「不会」会被怼；贴步骤才逐行批改；讲完概念强制自测
- **错题本**：按章节筛选、标记已掌握、localStorage 永久保存
- **打卡**：三档习题各至少 1 题 + 检测卷完成，才算本章打卡
- **综合期末模拟卷**：全册高频考点融合
- **深浅两套主题**：默认清新粉紫毛玻璃（粉+紫渐变），侧栏底部可切深色护眼

## 使用

直接双击 `index.html`，或访问 GitHub Pages 链接（见下）。

**手机端同样可以用**：浏览器打开同一个链接即可，导航变成横向滑动条，公式面板收进右下角的 `∑` 按钮，深色开关在标题右侧。建议在手机上「添加到主屏幕」，用起来更接近 App。

数据保存在**你自己浏览器**的 `localStorage`（键名 `gaoshu_yanzhu_v1`）：

- 换浏览器、换设备、清除站点数据，打卡和错题都会丢
- **电脑上做的进度不会同步到手机**，两边各自独立
- 同学打开同一个链接，看到的是各自独立的记录，**不互通**

## 发布到 GitHub Pages

```bash
# 在 github-pages 目录下
git init
git add .
git commit -m "高数雷霆助教：单页离线版"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

然后：仓库 **Settings → Pages → Build and deployment → Source 选 Deploy from a branch → Branch 选 main / (root) → Save**。

等 1~2 分钟，访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

> 文件名必须叫 `index.html` 才能用这个短地址。如果直接点仓库里的 html 文件，只会看到源码，必须开 Pages 才是网页。

## 注意

- 试卷来自校内资料，**仅供个人复习**。公开仓库等于把学校真题传播出去，建议用 **Private 仓库 + 邀请同学为 Collaborator**（私有仓库开 Pages 需要 GitHub Pro；免费方案是本地打开文件，或用 Cloudflare Pages / Vercel 私有部署）。
- 页面没有后端，所有判分都在浏览器里完成：选择题、填空题自动判，解答题按「得分点自评」给分。
